# Rod Solutions LLC Website

Official static website starter for Rod Solutions LLC.

## Included
- Responsive one-page website
- Rod Solutions branding
- Real project photos
- Services: Asbestos Abatement, Demolition, General Contracting
- Project gallery
- Before/after section
- Estimate request form using the visitor's email app
- Mobile navigation

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/images/`
